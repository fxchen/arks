# Casey's consulting vault

My working memory: client engagements, what I know about the people and
companies I work with, and how I run the practice. Built on the ARKS pattern
(github.com/fxchen/arks); the house rules an agent follows here are in
[`AGENTS.md`](AGENTS.md).

## Map

- **Live engagements** → [`Action/projects/`](Action/projects/) — one living
  doc each. Currently: [site-relaunch](Action/projects/site-relaunch.md).
- **People** → [`Knowledge/people/`](Knowledge/people/) — one page per
  person, my current picture, sources cited.
- **Concepts** → [`Knowledge/concepts/`](Knowledge/concepts/) — how I price,
  how I scope, things I've figured out.
- **Raw material** → [`Records/`](Records/) — an append-only collection of
  dated, write-once Records. Look here for "what was actually said."
- **Furniture** → [`System/`](System/) — templates, decisions, routines.

## Where new things go

A meeting or call → a dated Record in `Records/` (the capture routine does
this). A conclusion about a person or topic → their page in `Knowledge/`,
citing the Record. Anything with a deadline → the engagement's one living doc
in `Action/projects/`.
